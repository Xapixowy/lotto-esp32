## Commits

Before creating a commit, read `~/.config/git/template` and follow its commit message format, including the appropriate type and emoji.

## Agent skills

### Issue tracker

Track issues and specs in GitHub Issues. Read
`docs/agents/issue-tracker.md` before working with tickets.

### Triage labels

Use the default triage labels. Read
`docs/agents/triage-labels.md` when triaging or labeling issues.

### Domain docs

Use one root glossary and `docs/adr/` for decisions. Read
`docs/agents/domain.md` before exploring the codebase.
