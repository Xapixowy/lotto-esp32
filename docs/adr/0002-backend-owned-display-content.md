# Backend-owned display content

The backend defines ordered slides using stable game IDs, labels, and labeled result groups with value arrays and kinds such as simple and additional. Firmware renders each complete group on one screen using up to 20 values; it rotates between groups but never splits a group across pages. Oversized groups are rejected rather than truncated. This replaces the earlier within-group pagination rule at the owner's request. Each replacement snapshot is authoritative; firmware does not append results or infer history. This keeps game-specific content changes in the backend while retaining a bounded rendering contract on the device.
