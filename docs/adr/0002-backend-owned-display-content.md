# Backend-owned display content

The backend defines ordered slides using stable game IDs, labels, and labeled result groups with value arrays and kinds such as simple and additional. Firmware renders each complete group as one page using up to 20 values. Arrows move through group pages across game boundaries, and screen lock holds the selected page without automatic group rotation. Unlocked pages advance every ten seconds; unlocking restarts that interval. Oversized groups are rejected rather than truncated. Each replacement snapshot is authoritative; firmware does not append results or infer history. This keeps game-specific content changes in the backend while retaining a bounded rendering contract on the device.
